# discord_ITBOT

Discord 農業模擬遊戲（持續開發版）。

## 目前實作重點（已更新）
- 指令分流
  - `/farm`：農地 5×5 主玩法
  - `/farmui`：轉化爐 / 背包 / 穀倉 / 好友 / 農夫寶典
- 互動模式
  - 全 Ephemeral
  - 地塊點擊後使用 Select Menu 動態操作
  - UI 版本機制：舊畫面會失效，避免重複 UI 混亂
- 農地功能
  - 解鎖、種植、施肥、升級、澆水、收割、吃掉、資訊
  - 成熟地塊用綠色按鈕樣式標示
  - 養分狀態文字：`地塊# / 等級 / 養分當前與上限`
- 澆水規則
  - 遊戲內 1 日 = 現實 1 分鐘
  - 每次澆水加速 1 日，冷卻 3 日，不可疊加
- 轉化爐與作物價值
  - 消耗金幣抽種籽
  - 高等級作物抽取權重提高
  - 高等級作物有機率一次掉 2 顆種籽
  - 高等級作物售價顯著提高
- 穀倉功能（2×5）
  - 欄位解鎖、欄位升級、吃掉、全部賣出
  - 顯示欄位容量與等級
  - 賣出二次確認
  - 市場稀缺/過剩價格加成顯示
- 熟練度（每作物獨立）
  - 作物有獨立熟練等級：業餘(1)→學徒(2)→農夫(3)→神農(4)
  - 成功收割 +1 EXP
  - 升級需求：`20 + (作物等級 × 10)`（目前有套全局難度係數）
  - 收成量：`1 + 該作物熟練等級`
  - `/farmui` 的「農夫寶典」可查詢每作物等級/經驗/增益
- 好友與拜訪
  - 新增好友（只顯示有遊玩且未加好友者）
  - 拜訪好友農地（唯讀模式：僅查看資訊/返回）
  - 拜訪時對好友生長中作物加速 30%，同好友冷卻 30 日
- 本地持久化
  - 玩家資料儲存於 `player_data/<user_id>.json`
  - 大部分關鍵動作即時保存，tick 另有全量保存

## 啟動
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
DISCORD_TOKEN=xxx python bot.py
```

## 測試
```bash
python -m unittest test_game_logic.py
```
